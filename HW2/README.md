# HW2 model experiments

Install dependencies with `python -m pip install -r HW2/requirements.txt` from the repository root, using your chosen Python environment. Run `python HW2/main.py`. Paths are resolved relative to main.py, so running main.py from PyCharm also works. CUDA is selected automatically when available in your PyTorch installation; otherwise the suite uses CPU. VGG and ResNet may take substantial time on CPU.

Change `LEARNING_RATE` in main.py to set Adam's learning rate for all four models. Other settings control the number of epochs, batch size, enabled models, split fractions, seed, device, and early stopping patience. For a quick check, use `EPOCHS = 1` and `MAX_SAMPLES = 1000`; restore `MAX_SAMPLES = None` for assignment results. Run separate suites with learning rates 0.1, 0.01, and your chosen third rate to complete the assignment tables. The default third rate is 0.001.

The DNN uses fully connected layers of 256 and 128 units. ConvNet uses two convolution/pooling blocks and a 128-unit classifier. VGG implements the VGG11 convolution layout from scratch, with ceiling-mode pooling and a smaller classifier for 28 by 28 inputs. ResNet implements the ResNet18 basic-block layout from scratch, with a single-channel 3 by 3 stem and no initial max pooling for MNIST. These are MNIST adaptations; no pretrained weights or predefined ConvNet models are used. Add a model class to models.py and MODEL_REGISTRY, then include its name in ENABLED_MODELS to extend the suite.

All models return logits and use PyTorch CrossEntropyLoss with integer labels, along with Adam. Pixels are normalized to [0, 1]. The labeled CSV is split into stratified training, validation, and local test subsets with approximate proportions 80/10/10. The exact row indices are saved and reused across models. test.csv is unlabeled competition data and is not used for local metric calculation.

Every run creates a new timestamped directory under results. summary.csv contains local test accuracy, macro F1, and macro one-vs-rest ROC AUC for the checkpoint selected using validation accuracy, with lower validation loss breaking ties. It also contains each model's maximum validation F1 and AUC across epochs and the epochs where those maxima occurred. Those two maxima can come from different epochs. Test metrics are evaluated once per model after checkpoint selection. Models are compared and the overall winner is selected using validation performance; choosing checkpoints by their best test scores would bias the evaluation.

Each model directory contains best_weights.pt, history.csv, learning_curves.png, and test_predictions.npz. The run directory also contains config.json, split_indices.npz, best_model.json, and best_model_test_roc.png. Accuracy, F1, and AUC are saved as fractions from 0 to 1. Multiply accuracy by 100 for a percentage. Early stopping monitors the same validation criterion as checkpoint selection. A high learning rate can lead to poor or non-finite training; the suite raises an error for non-finite loss or predictions.

To restore weights, instantiate `MODEL_REGISTRY[name]()`, load the checkpoint with `torch.load(path, map_location="cpu", weights_only=True)`, and call `model.load_state_dict(checkpoint["state_dict"])`, followed by `model.eval()` for inference. Feed normalized tensors with shape `(batch, 1, 28, 28)`.

Cross-entropy expects logits as described in https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html. Macro one-vs-rest AUC uses class probabilities as described in https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html.

## Kaggle submission after training

Run `.\HW2\.venv\Scripts\python.exe HW2/submission.py` from the repository root to generate HW2/submission.csv from existing weights. This performs inference without retraining. The default run is results/lr0.001, whose ConvNet has the highest validation accuracy among the three completed learning-rate suites (99.19%). The script reads that run's best_model.json to select its checkpoint. Original test-row order is preserved, preprocessing matches training, and the output is checked against sample_submission.csv. Upload only submission.csv to Kaggle. The accompanying submission.metadata.json records the source checkpoint, its hash, learning rate, epoch, validation metrics, and prediction counts for your records.

For a different experiment, pass `--run-dir HW2/results/lr0.01`. By default, the model is selected from that run's best_model.json; use `--model ResNet` to explicitly select another saved model in the run. Other options include `--output`, `--batch-size`, and `--device`. Existing output files are protected; pass `--overwrite` to regenerate the same output. Since competition labels are withheld, this process cannot report accuracy on the competition test images.
